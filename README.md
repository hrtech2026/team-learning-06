## Как работаем

В чате договариваемся, кто берёт какую задачу, и распределяем разделы по ролям. Как только раздел готов, отдаём его на ревью. Перед сдачей этапа при необходимости сверяемся всей командой. Правки сначала обсуждаем в чате, а когда договорились, оформляем Pull Request.

## Сдача

```text
1. Все документы в ветке main
2. Проверка validate-docs.yml зелёная
3. data/meta.yml актуален: состав, роли, этап
4. Карточка на доске переведена в нужную колонку
5. В комментарии к Pull Request есть тег: "Сдаю этап N"
```
