# Глоссарий

## Основные термины

| Термин | Значение в проекте |
|---|---|
| Навигатор развития | Сервис, в котором сотрудник и руководитель превращают зону роста после review в рабочую задачу и обсуждают результат |
| Performance review | Разговор о результатах работы, на котором может появиться зона роста |
| Зона роста | Навык или наблюдаемое рабочее поведение, которое сотрудник хочет развивать |
| Компетенция | Способность, которая проявляется в рабочем поведении и результате |
| Элемент новой роли | Отдельное действие или обязанность, которую можно попробовать в текущей работе |
| Рабочий эксперимент | Обратимая задача на 10–20 рабочих дней с заданным результатом, сроком и возможностью остановки |
| Артефакт | Материал, по которому можно обсуждать результат. Например, сводка встречи или план действия |
| Критерий результата | Заранее согласованный признак, по которому участники проверяют результат |
| Рефлексия | Краткая запись результата или его отсутствия, сложности и следующего вопроса. Может содержать ссылку на артефакт |
| Психологическая безопасность | Возможность отказаться, сообщить о сложности и возражать без отрицательных кадровых последствий |
| Ручной разбор | Работа назначенного специалиста HR/L&D по спору, просрочке или отсутствию пригодной задачи |
| Исходный замер, baseline | Разметка семи опубликованных карточек по наличию артефакта и срока для сравнения с учебным прогоном |
| Пилот | Проверка решения на одной роли и одном ограниченном рабочем эксперименте после прогона по семи карточкам |

## Модели и обозначения

| Термин | Значение |
|---|---|
| AS-IS | Текущий путь от зоны роста до согласования действия или обходного пути |
| TO-BE | Проектируемый путь от зоны роста до обсуждения результата |
| IGP | Индивидуальный план роста. В AS-IS это один из форматов фиксации следующего шага |
| C01–C07 | Семь исходных активностей из открытой программы GitLab |
| M1 | Доля карточек с явным артефактом |
| M2 | Доля карточек с явно указанной датой, длительностью или периодичностью действия |
| M3 | Доля карточек, одновременно удовлетворяющих M1 и M2 |
| P1–P7 | Проблемы текущего процесса из AS-IS |
| T01–T10 | Шаги целевого процесса |
| K01–K10 | Карточки задач для учебного прогона |
| R1–R8 | Риски и проверки для целевого процесса |
| US, UC, NFR | Пользовательская история, сценарий использования и нефункциональное требование |
| HR/L&D | Специалисты по работе с сотрудниками и развитию. Ведут каталог и разбирают назначенные случаи |

## Человеческий контроль и уровни автоматизации

| ID | Значение |
|---|---|
| H1 | Сотрудник выбирает, изменяет или отклоняет задачу. Срок — пять рабочих дней |
| H2 | Руководитель проверяет объём, срок, доступы и критерий. Срок — три рабочих дня |
| H3 | Сотрудник и руководитель обсуждают результат и согласуют итог. Срок — пять рабочих дней после появления сводки |
| L0 | Человек выбирает задачу и принимает решение. Сервис хранит результат |
| L1 | Сервис готовит сводку из согласованных полей и источников, решения принимают люди |
| L2 | Сервис предлагает вариант из каталога с объяснением. Для запуска обязательны H1 и H2 по одной версии |
| L3, L4 | Уровни самостоятельного действия системы за пределами процесса развития |

## Данные и компоненты

| Термин | Значение |
|---|---|
| Каталог | Версионируемый список задач. У карточки есть роль, компетенция, действие, срок, критерий, условия, владелец и срок актуальности |
| Сервис маршрута | Проверяет права и версии, меняет статусы по разрешённым событиям и хранит решения |
| Сводка L1 | Отображение цели, действия, критерия, результата и следующего вопроса из маршрута |
| Предобработка | Проверка разрешённых полей входа модели и допустимых карточек |
| История маршрута | События и решения, которые видят участники конкретного маршрута |
| Технический аудит | Ролевой журнал операций, версий и оснований. Доступ проверяется отдельно от истории маршрута |
| Версия задачи | Набор согласуемых полей, включая действие, срок, нагрузку, доступы и критерий результата |
| Версия входа и `input_hash` | Запись разрешённых полей запроса и контрольное значение для сверки использованных данных |
| Внутренний контур | Среда пилота, в которой хранятся маршруты и работают правила и модель |

## Статусы маршрута

| Статус | Значение |
|---|---|
| Черновик | Сотрудник сохранил зону роста |
| На уточнении | Показаны варианты, уточняется цель или согласуется изменённая карточка |
| На подтверждении | Сотрудник выбрал версию через H1 и ждёт H2 |
| Активен | Руководитель подтвердил ту же версию, которую выбрал сотрудник |
| На рефлексии | Эксперимент закончился, сотрудник вводит результат |
| На обсуждении | Сводка готова к совместному рассмотрению через H3 |
| Нужна ручная проверка | Назначается разбор спора, просрочки или случая без пригодной карточки |
| Завершён | Согласован итог H3. История доступна для чтения до истечения срока хранения |
| Отменён | Сотрудник закрыл маршрут или участник остановил эксперимент. История доступна для чтения до истечения срока хранения |
